秋霞圃｜专业离线调查版
=======================

启动：
1. 解压整个文件夹（不要只拿出 index.html）。
2. 双击 index.html，使用 Chrome 或 Edge 打开。
3. 地图底图位于 assets/plan-1987-restyled.png，原始照片在 assets/photo0.jpg ... photo6.jpg（如果打包时存在）。

功能：
- 1987 年底图与 44 个历史编号点位
- 地图缩放、拖动、点位选择、路径显示/隐藏
- 按植物/建筑/全部筛选，按景区筛选，全文搜索
- 新增、编辑、删除调查记录
- 记录字段：类型、名称、学名、景区、点位、数量、鉴定状态、调查者、图上坐标、观察、生境、证据
- 可给记录添加多张照片
- 导出 CSV、GeoJSON、完整 JSON 备份（照片以 data URL 一并打包）
- 从 JSON 导入恢复
- 点击“地图点选新增”后在地图任意位置点击，建立带图上像素坐标的记录
- “路径草绘”模式：依次点击地图，双击结束并命名

数据保存说明：
- 数据默认保存在当前浏览器 localStorage 中。file:// 页面在不同浏览器或某些设置下的存储行为可能不同。
- 强烈建议经常点击“备份 / 恢复”→“下载完整备份（含照片）”。
- 导入备份会替换当前记录，请先备份当前数据。
- JSON 是最完整的备份格式。CSV 主要用于表格整理；GeoJSON 适合 GIS，但不保证所有记录都有经纬度。
- 历史点位及路径草图来自随附 JSON；路径状态为“未核验”，仅作为数字化草图，需现场核验。
- 本应用不联网，不提供云同步和多人协作。定位功能未启用，以避免离线环境下误报。
